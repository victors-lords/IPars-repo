# 🦁 AyLinux APT Paket Deposu

AyLinux işletim sistemi ve araçları için resmi Termux paket deposudur.

## 🚀 Kurulum & Kullanım

Depoyu Termux'a tek komutla ekleyin:

```bash
echo "deb [trusted=yes] https://victors-lords.github.io/aylinux-repo/ ./" > $PREFIX/etc/apt/sources.list.d/aylinux.list
apt update
```

### 📦 Paket Kurulumu:
```bash
apt install aylinux-banner
```
