# 🦁 İPars Resmi APT Paket Deposu

İPars ekosistemi ve Termux/Linux ortamları için geliştirilmiş resmi APT deposu.

---

## ⚡ Hızlı Kurulum

Depoyu Termux sisteminize tek komutla ekleyin:

```bash
echo "deb [trusted=yes] https://victors-lords.github.io/IPars-repo/ ./" > $PREFIX/etc/apt/sources.list.d/aylinux.list
apt update
```

---

## 📦 Mevcut Paketler

### 1. `aytop` 📊
Canlı, interaktif ve fütüristik sistem monitörü (`htop` alternatifi).
- CPU barları, RAM kullanımı, Uptime ve aktif süreçleri canlı görselleştirir.
```bash
apt install İmonitoring
İmonitoring 
```

### 2. `İPars-banner` 🦁
İPars resmi fütüristik karşılama ekranı ve Pars ASCII sanatı.
```bash
apt install İPars-banner
İPars-banner
```
